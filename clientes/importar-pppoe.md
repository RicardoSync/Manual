# Importar PPPoE

<figure><img src="../.gitbook/assets/image (42).png" alt="Pantalla de importación de clientes PPPoE"><figcaption><p>Importación de clientes PPPoE</p></figcaption></figure>

Importa clientes PPPoE desde los secretos configurados en tu MikroTik.

### Importación

<figure><img src="../.gitbook/assets/image (43).png" alt="Opción para importar clientes PPPoE"><figcaption><p>Selecciona la importación por PPPoE</p></figcaption></figure>

1. Selecciona la opción **2** para importar clientes PPPoE.

<figure><img src="../.gitbook/assets/image (44).png" alt="Selección de MikroTik para importar clientes PPPoE"><figcaption><p>Selecciona el MikroTik de origen</p></figcaption></figure>

2. Selecciona el MikroTik desde el que importarás los clientes.

<figure><img src="../.gitbook/assets/image (45).png" alt="Lista de clientes PPPoE disponibles para importar"><figcaption><p>Revisa los clientes disponibles</p></figcaption></figure>

3. Revisa la lista de clientes PPPoE disponibles.

{% hint style="info" %}
Solo se muestran los clientes habilitados en **PPPoE Secrets**. El sistema ignora los clientes inhabilitados.
{% endhint %}

Selecciona cada cliente mediante su casilla. También puedes usar **Seleccionar todos** para importarlos todos.

<figure><img src="../.gitbook/assets/image (46).png" alt="Control para seleccionar todos los clientes PPPoE"><figcaption><p>Selecciona todos los clientes</p></figcaption></figure>

4. Activa el selector superior para incluir todos los clientes. Después, confirma la importación.

<figure><img src="../.gitbook/assets/image (47).png" alt="Clientes PPPoE importados en la lista de clientes"><figcaption><p>Clientes importados correctamente</p></figcaption></figure>

Cuando finalice la importación, los clientes aparecerán automáticamente en la lista de clientes.
