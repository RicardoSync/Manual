# Importar SimpleQueue

<figure><img src="../.gitbook/assets/Captura de Pantalla 2026-08-29 a la(s) 20.56.47.png" alt="Pantalla para importar clientes SimpleQueue"><figcaption><p>Importación de clientes SimpleQueue</p></figcaption></figure>

Importa los clientes de las listas SimpleQueue de tu MikroTik.

Durante la importación, todos los clientes reciben el mismo paquete. También reciben la fecha de pago y el día de corte actuales.

{% hint style="warning" %}
Después de importar, revisa y actualiza el paquete, el día de corte y la fecha de pago de cada cliente.
{% endhint %}

### Importacion

<figure><img src="../.gitbook/assets/Captura de Pantalla 2026-08-29 a la(s) 20.58.21.png" alt="Opción para importar clientes por SimpleQueue"><figcaption><p>Selecciona la importación por SimpleQueue</p></figcaption></figure>

1. Selecciona la opción **1** para importar clientes por SimpleQueue.

<figure><img src="../.gitbook/assets/Captura de Pantalla 2026-08-29 a la(s) 20.58.55.png" alt="Selección de MikroTik para importar clientes"><figcaption><p>Selecciona el MikroTik de origen</p></figcaption></figure>

2. Selecciona el MikroTik desde el que importarás los clientes.

<figure><img src="../.gitbook/assets/Captura de Pantalla 2026-08-29 a la(s) 20.56.47.png" alt="Lista de clientes disponibles para importar"><figcaption><p>Selecciona los clientes que deseas importar</p></figcaption></figure>

3. Revisa la lista de clientes disponibles.

Selecciona cada cliente mediante su casilla. También puedes usar **Seleccionar todos** para importarlos todos.

{% file src="../.gitbook/assets/Captura de Pantalla 2026-08-29 a la(s) 21.00.37.png" %}

<figure><img src="../.gitbook/assets/Captura de Pantalla 2026-08-29 a la(s) 21.01.09.png" alt="Mensaje de importación completada"><figcaption><p>Confirmación de importación</p></figcaption></figure>

Cuando finalice la importación, verás un mensaje de confirmación. El sistema te redirigirá a la lista de clientes.
