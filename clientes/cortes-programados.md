# Cortes programados

<figure><img src="../.gitbook/assets/image (88).png" alt=""><figcaption></figcaption></figure>

Los cortes programados suspenden el servicio de un cliente en horarios definidos. Úselos cuando necesite aplicar una suspensión recurrente durante ciertos días y horas.

Puede crear un corte desde cualquiera de estas rutas:

* **Lista de clientes → Perfil de cliente → Programar horarios**
* **Lista de clientes → Opciones → Programar corte**

### Crear un corte programado

<figure><img src="../.gitbook/assets/image (89).png" alt=""><figcaption></figcaption></figure>

{% stepper %}
{% step %}
#### Defina el horario

Seleccione la **hora de inicio** de la suspensión. Luego indique la hora de **reactivación automática**.
{% endstep %}

{% step %}
#### Seleccione los días

<figure><img src="../.gitbook/assets/image (90).png" alt=""><figcaption></figcaption></figure>

Elija los días en que se aplicará el corte. Puede seleccionar todos los días o solo días específicos.
{% endstep %}

{% step %}
#### Guarde los cambios

Guarde la configuración para activar el horario programado.
{% endstep %}
{% endstepper %}

### Gestionar cortes programados

<figure><img src="../.gitbook/assets/image (91).png" alt=""><figcaption></figcaption></figure>

Vaya a **Clientes → Horarios de corte** para revisar los cortes programados.

Desde este listado puede editar, desactivar o eliminar cada horario.
