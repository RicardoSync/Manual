# Lista de clientes

<figure><img src="../.gitbook/assets/image (38).png" alt="Vista de la lista de clientes"><figcaption><p>Lista de clientes</p></figcaption></figure>

La lista de clientes centraliza el directorio de tu empresa.

Consulta la información de cada cliente y su estado desde un solo lugar.

### Filtros

<figure><img src="../.gitbook/assets/image (39).png" alt="Filtros de la lista de clientes"><figcaption><p>Filtros disponibles</p></figcaption></figure>

Usa los filtros para mostrar únicamente los clientes que necesitas revisar.

Puedes filtrar por comunidad, MikroTik o plan.

### Exportaciones

<figure><img src="../.gitbook/assets/image (40).png" alt="Opciones para exportar clientes"><figcaption><p>Opciones de exportación</p></figcaption></figure>

Selecciona **Exportar** para descargar información de tus clientes.

Puedes exportar:

* Los clientes que coinciden con los filtros aplicados.
* Los clientes seleccionados.
* Todos los clientes.

Elige el formato **Excel** o **PDF**. También puedes seleccionar los datos de cada cliente que incluirás.

### Acciones

<figure><img src="../.gitbook/assets/image (41).png" alt="Acciones disponibles para un cliente"><figcaption><p>Acciones por cliente</p></figcaption></figure>

Usa las acciones de cada fila para administrar un cliente sin salir de la lista.

1. **Cobro:** registra el cobro mensual del cliente.
2. **Ver perfil:** abre el perfil completo del cliente.
3. **Suspender:** pausa el servicio del cliente.
4. **WhatsApp:** abre una ventana para enviarle un mensaje.
5. **Sincronizar router:** sincroniza la información con el router.
6. **Programar corte:** programa un horario para cortar el servicio de internet.
7. **Eliminar:** elimina el cliente.
