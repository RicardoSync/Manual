# Aviso personal

<figure><img src="../.gitbook/assets/image (92).png" alt=""><figcaption></figcaption></figure>

Esta opción permite enviar un mensaje de WhatsApp personalizado a un cliente. El mensaje se envía de forma privada.

Puede acceder desde cualquiera de estas rutas:

* **Lista de clientes → Acciones → ícono de WhatsApp**
* **Perfil de cliente → Mensaje directo**

### Enviar un aviso

1. Abra el mensaje directo del cliente.
2. Escriba el aviso que desea enviar.
3. Revise el contenido y envíe el mensaje.
