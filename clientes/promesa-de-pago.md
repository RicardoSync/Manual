# Promesa de pago

<figure><img src="../.gitbook/assets/image (76).png" alt="Opción Promesa de pago en el perfil de un cliente"><figcaption><p>Registro de una promesa de pago</p></figcaption></figure>

Una promesa de pago otorga tiempo adicional a un cliente para realizar su pago.

Puedes registrarla aunque el servicio siga activo o ya esté suspendido.

### Registrar una promesa de pago

1. Ve a **Clientes**.
2. Abre el perfil del cliente.
3. Selecciona **Más opciones**.
4. Selecciona **Promesa de pago**.
5. Define la nueva fecha límite de pago.
6. Confirma la acción.

<figure><img src="../.gitbook/assets/image (77).png" alt="Selector de nueva fecha límite para la promesa de pago"><figcaption><p>Define la nueva fecha límite</p></figcaption></figure>

Si el cliente estaba suspendido, el sistema restaura su servicio automáticamente.

{% hint style="info" %}
El sistema notifica al cliente por WhatsApp cuando esta función está configurada.
{% endhint %}

### Confirmación

<figure><img src="../.gitbook/assets/image (78).png" alt="Promesa de pago registrada en la información del cliente"><figcaption><p>Promesa de pago registrada</p></figcaption></figure>

Después de confirmar, la promesa de pago aparece debajo de la información del cliente.
