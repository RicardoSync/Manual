# Comunidades

### ¿Qué son las comunidades?

Las comunidades, también llamadas nodos de cobertura, organizan las zonas donde ofreces internet.

Registra localidades, fraccionamientos, pueblos o sectores de tu red. Asigna las antenas y paquetes disponibles en cada zona.

Esto mantiene tu infraestructura organizada y facilita la gestión por sector.

<figure><img src="../.gitbook/assets/image (107).png" alt="Vista principal del módulo de Comunidades"><figcaption><p>Vista principal del módulo de Comunidades.</p></figcaption></figure>

### Crear una comunidad

1. Selecciona **Nueva Comunidad / Nodo**.
2. Escribe el nombre de la zona de cobertura.
3. Selecciona las antenas (AP) disponibles.
4. Selecciona los paquetes de internet que ofrecerás.
5. Guarda los cambios.

La comunidad queda disponible en el catálogo de nodos de cobertura.

<figure><img src="../.gitbook/assets/image (108).png" alt="Formulario para crear una comunidad"><figcaption><p>Formulario para crear y configurar una comunidad.</p></figcaption></figure>

### Consultar el resumen

La parte superior muestra indicadores de tu infraestructura:

* **Total de comunidades** registradas.
* **Total de antenas AP** disponibles.
* **Total de paquetes** disponibles en el sistema.

La gráfica de distribución muestra los clientes conectados por comunidad. Úsala para identificar las zonas con mayor demanda.

<figure><img src="../.gitbook/assets/image (109).png" alt="Indicadores y gráfica de distribución de clientes"><figcaption><p>Indicadores de infraestructura y distribución de clientes por comunidad.</p></figcaption></figure>

### Usar el catálogo de nodos

El catálogo lista todas las comunidades registradas. Cada registro muestra:

* El nombre de la comunidad y su fecha de registro.
* Las antenas (AP) asignadas, identificadas con etiquetas azules.
* Los paquetes disponibles, identificados con etiquetas verdes y su precio.

<figure><img src="../.gitbook/assets/image (110).png" alt="Catálogo de nodos de cobertura"><figcaption><p>Catálogo de nodos con antenas y paquetes asignados.</p></figcaption></figure>

### Editar una comunidad

Selecciona **Editar**, identificado con el ícono de lápiz amarillo. Puedes cambiar el nombre, agregar antenas o actualizar los paquetes disponibles.

Guarda los cambios para aplicar la configuración a la comunidad.

<figure><img src="../.gitbook/assets/image (111).png" alt="Opción para editar una comunidad"><figcaption><p>Usa el ícono de lápiz para editar la comunidad.</p></figcaption></figure>

### Eliminar una comunidad

Selecciona **Eliminar**, identificado con el ícono de bote de basura rojo. El sistema solicita una confirmación antes de eliminarla definitivamente.

{% hint style="warning" %}
Confirma que la comunidad ya no requiere configuración antes de eliminarla.
{% endhint %}
