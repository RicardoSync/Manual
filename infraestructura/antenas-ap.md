# Antenas AP

### ¿Qué son las antenas AP?

El módulo **Antenas AP** concentra el inventario de equipos inalámbricos de tu red.

Registra las antenas instaladas en torres o nodos. Define su modelo, dirección IP, router MikroTik asociado y tipo de uso.

Puedes identificar equipos para distribuir señal, crear enlaces punto a punto o conectar clientes.

<figure><img src="../.gitbook/assets/image (113).png" alt="Vista principal del módulo de Antenas AP"><figcaption><p>Vista principal del módulo de Antenas AP.</p></figcaption></figure>

### Registrar una antena AP

1. Selecciona **Registrar Nueva Antena AP**.
2. Captura el nombre, modelo y tipo de equipo.
3. Indica la dirección IP, el router MikroTik y el usuario de acceso.
4. Guarda el registro.

Usa nombres descriptivos para identificar cada equipo rápidamente. Por ejemplo, `Sectorial Norte - LiteBeam`.

<figure><img src="../.gitbook/assets/image (114).png" alt=""><figcaption></figcaption></figure>

### Consultar el resumen

La parte superior muestra la clasificación de los equipos registrados:

* **Total Antenas AP:** todos los equipos de tu inventario.
* **Sectoriales AP:** equipos que distribuyen señal a los clientes.
* **Enlaces PTP:** equipos que conectan dos ubicaciones de la red.
* **Estaciones CPE:** equipos receptores instalados para clientes.

La gráfica de cobertura muestra los clientes conectados por antena y comunidad. Úsala para detectar equipos con alta demanda.

<figure><img src="../.gitbook/assets/image (115).png" alt=""><figcaption></figcaption></figure>

### Usar el catálogo de dispositivos

El catálogo muestra todos los equipos registrados. Cada registro incluye:

* Nombre y modelo de la antena.
* Router MikroTik asociado y dirección IP.
* Tipo de equipo y usuario de acceso.

<figure><img src="../.gitbook/assets/image (117).png" alt=""><figcaption></figcaption></figure>

### Editar una antena

Selecciona **Editar**, identificado con el botón amarillo. Puedes actualizar el nombre, modelo, dirección IP o credenciales de acceso.

Guarda los cambios para mantener actualizado el inventario.

<figure><img src="../.gitbook/assets/image (118).png" alt=""><figcaption></figcaption></figure>

### Eliminar una antena

Selecciona **Eliminar**, identificado con el botón rojo. El sistema solicita una confirmación antes de borrar el equipo.

<figure><img src="../.gitbook/assets/image (119).png" alt=""><figcaption></figcaption></figure>

{% hint style="warning" %}
Elimina una antena solo cuando se haya retirado o dado de baja de la red.
{% endhint %}
