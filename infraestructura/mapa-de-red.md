# Mapa de Red

### ¿Qué es el mapa de red?

El mapa de red muestra la ubicación geográfica de tus clientes.

Úsalo para revisar la cobertura, identificar zonas con mayor concentración y planificar instalaciones o reparaciones. También permite visualizar clientes con adeudos o servicios suspendidos.

<figure><img src="../.gitbook/assets/image (120).png" alt="Vista del mapa interactivo de red"><figcaption><p>Vista principal del mapa interactivo de red.</p></figcaption></figure>

### Buscar y filtrar clientes

La barra superior permite localizar clientes y reducir la información visible.

* **Buscar cliente:** escribe el nombre, DNI, RFC o dirección IP.
* **Estado:** muestra clientes activos, con adeudo o suspendidos.
* **Comunidad:** limita el mapa a una zona de cobertura.
* **Centrar mapa:** ajusta la vista para mostrar los clientes visibles.

<figure><img src="../.gitbook/assets/image (121).png" alt=""><figcaption></figcaption></figure>

### Interpretar los marcadores

Cada cliente aparece con un marcador según el estado de su servicio:

* **Verde:** cliente activo y al corriente.
* **Amarillo:** cliente con adeudo pendiente.
* **Rojo:** cliente con el servicio suspendido.

Cuando varios clientes están cerca, el mapa los agrupa en un marcador con un número. Acerca el mapa para ver cada ubicación individualmente.

### Cambiar la vista del mapa

Selecciona el ícono de capas, ubicado en la parte superior derecha. Puedes elegir entre vista de calles, satélite, satélite con nombres y modo oscuro.

Estas opciones facilitan ubicar domicilios y planificar recorridos técnicos.

<figure><img src="../.gitbook/assets/image (122).png" alt=""><figcaption></figcaption></figure>

### Consultar la ficha de un cliente

Selecciona un marcador para abrir la ficha rápida del cliente. Incluye:

* Nombre, estado, plan contratado, dirección y conexión.
* Un acceso directo a WhatsApp, si el cliente tiene un teléfono registrado.
* Opciones para ver el perfil o abrir la ubicación en Google Maps.

<figure><img src="../.gitbook/assets/image (123).png" alt=""><figcaption></figcaption></figure>

Usa **Ver perfil** para consultar la información completa de cobranza y servicio.
