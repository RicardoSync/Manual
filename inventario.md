# Inventario



## Gestión de inventario y bodega

<figure><img src=".gitbook/assets/image (163).png" alt=""><figcaption></figcaption></figure>

El módulo **Inventario** permite administrar equipos y dispositivos físicos registrados en el sistema.

### Consultar y visualizar equipos

<figure><img src=".gitbook/assets/image (164).png" alt=""><figcaption></figcaption></figure>

Puedes revisar el inventario desde las tarjetas de resumen y la tabla principal.

* **Resumen en tarjetas:** muestra el total registrado, los equipos asignados, los disponibles en bodega y los rentados.
* **Lista completa:** incluye tipo, marca, modelo, dirección MAC, número de serie, propiedad y asignación.
* **Búsqueda rápida:** ordena las columnas o busca por marca, modelo o dirección MAC.

### Registrar un nuevo equipo

{% stepper %}
{% step %}
#### Inicia el registro

Haz clic en **Registrar Equipo en Bodega**.
{% endstep %}

{% step %}
#### Completa la información

Ingresa el tipo de dispositivo, marca, modelo, dirección MAC, serie y estado.

También puedes añadir notas opcionales.
{% endstep %}

{% step %}
#### Guarda el equipo

Guarda el registro para incluir el equipo en el catálogo de bodega.

<figure><img src=".gitbook/assets/image (165).png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}

### Editar información de un equipo

{% stepper %}
{% step %}
#### Selecciona el equipo

Localiza el equipo en la tabla y haz clic en **Editar Equipo**.
{% endstep %}

{% step %}
#### Actualiza sus datos

Corrige la serie, marca o condición de propiedad según sea necesario.
{% endstep %}

{% step %}
#### Guarda los cambios

Guarda el formulario para actualizar el registro.

<figure><img src=".gitbook/assets/image (166).png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}

### Regresar un equipo a bodega

Esta acción está disponible para equipos asignados a un cliente.

1. Haz clic en **Regresar a Bodega**.
2. Confirma la acción cuando el sistema lo solicite.
3. El equipo se desvincula del cliente y queda como **Disponible en Bodega**.

<figure><img src=".gitbook/assets/image (168).png" alt=""><figcaption></figcaption></figure>

### Eliminar un equipo

Usa esta opción solo para equipos dados de baja o destruidos.

{% hint style="warning" %}
La eliminación retira definitivamente el equipo del catálogo de inventario.
{% endhint %}

1. Haz clic en **Eliminar Equipo**.
2. Confirma la eliminación cuando el sistema lo solicite.
