Configure el documento que define las reglas de uso del servicio. El sistema utiliza esta información para generar contratos claros y actualizados.

### Configurar los términos y condiciones

El formulario tiene tres partes principales.

#### Título del documento

Escriba el encabezado principal de las reglas del servicio.

Por ejemplo:

* `Términos y condiciones generales del servicio de internet`
* `Políticas de uso de la red`

#### Versión del documento

Use un número de control para identificar cada actualización. Por ejemplo, use `1.0` para la primera versión.

Cuando modifique las condiciones, cambie el número a `2.0`. Así podrá identificar qué versión aceptó cada cliente.

#### Editor de cláusulas

Escriba o pegue las reglas del servicio en el editor. Use las herramientas disponibles para dar formato al documento:

* Aplique **negrita**, _cursiva_ o subrayado.
* Cree listas numeradas para las cláusulas.
* Use listas con viñetas para condiciones o requisitos.

Organice las cláusulas antes de guardar. Esto facilita la lectura del contrato impreso.
