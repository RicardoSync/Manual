## Ventas directas

El módulo de Ventas Directas registra productos, repuestos, equipos, accesorios y servicios.

También permite consultar cada transacción y generar su comprobante en PDF.

### Consulta indicadores y resumen

<figure><img src="../.gitbook/assets/image (179).png" alt=""><figcaption></figcaption></figure>

Las tarjetas superiores muestran cuatro indicadores clave:

* **Total ventas:** cantidad total de notas de venta registradas.
* **Total recaudado:** importe acumulado de todas las ventas.
* **Ventas a clientes:** ventas vinculadas con un suscriptor registrado.
* **Piezas vendidas:** cantidad total de artículos entregados.

### Consulta el historial de ventas

<figure><img src="../.gitbook/assets/image (180).png" alt=""><figcaption></figcaption></figure>

La tabla de ventas muestra el detalle de cada transacción:

* Folio único, como `VTA-00001`, y fecha y hora de registro.
* Producto o servicio, descripción, cantidad, precio unitario y monto total.
* Vendedor, cliente y equipo asociado.

Una venta al público general se identifica como **Venta Directa**.

Usa el buscador y los filtros para localizar ventas por folio, producto, vendedor o cliente.

### Genera comprobantes de venta

En la columna de acciones de cada venta tienes dos opciones:

* **Ver PDF:** abre el comprobante para revisarlo o imprimirlo.
* **Descargar PDF:** guarda el recibo directamente en tu equipo.

<figure><img src="../.gitbook/assets/image (181).png" alt=""><figcaption></figcaption></figure>

### Inicia el registro

Haz clic en **Registrar Nueva Venta**.
{% endstep %}

### Captura los datos de la venta

Completa los siguientes campos:

* **Producto / Servicio:** artículo o servicio vendido.
* **Descripción:** detalles del artículo o notas adicionales. Este campo es opcional.
* **Cantidad** y **Precio unitario:** el sistema calcula el monto total automáticamente.

<figure><img src="../.gitbook/assets/image (182).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Vincula un cliente si aplica

Activa la vinculación a cliente para seleccionar el suscriptor y su equipo relacionado.

Este paso es opcional para ventas al público general.

<figure><img src="../.gitbook/assets/image (183).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

### Registra y genera el comprobante

Haz clic en **Registrar Venta & Generar PDF**.

El sistema guarda la transacción, actualiza el historial y genera el comprobante oficial.
