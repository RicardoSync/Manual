# Métodos de pago

## Gestión de métodos de pago

El módulo **Métodos de pago** administra las formas de cobro disponibles.

Estas opciones aparecen en el punto de venta y en caja. Puede configurar efectivo, transferencias, depósitos, tarjetas y otros medios de pago.

### Consultar métodos de pago



La parte superior muestra el total de métodos registrados y activos.

La tabla principal incluye:

* **Número:** identificador del método.
* **Nombre:** por ejemplo, _Transferencia BBVA_ o _Efectivo en ventanilla_.
* **Descripción e instrucciones:** cuentas, CLABE o notas para el cobrador.
* **Estado:** disponibilidad actual del método.

### Crear un método de pago

<figure><img src="../.gitbook/assets/image (188).png" alt=""><figcaption></figcaption></figure>

1. Seleccione **Nuevo método de pago**.
2. Ingrese el **Nombre del método**. Este campo es obligatorio.
3. Agregue una **Descripción o instrucciones**, si corresponde.
4. Seleccione **Guardar**.

El método queda disponible inmediatamente en las pantallas de cobro.

### Editar un método de pago

<figure><img src="../.gitbook/assets/image (189).png" alt=""><figcaption></figcaption></figure>

1. Ubique el método en la tabla.
2. Seleccione **Editar método** con el icono de lápiz.
3. Actualice el nombre, la descripción o las instrucciones.
4. Seleccione **Guardar**.

Los cambios se aplican en todo el sistema.

### Eliminar un método de pago

1. Ubique el método que ya no utilizará.
2. Seleccione **Eliminar método** con el icono de papelera.
3. Confirme la acción.

El sistema desactiva el método. No aparecerá en futuros cobros.
