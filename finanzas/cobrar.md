# Cobrar

<figure><img src="../.gitbook/assets/image (170).png" alt=""><figcaption></figcaption></figure>

El módulo de Caja permite cobrar mensualidades, abonos y servicios rápidamente.

### Buscar y seleccionar un cliente

<figure><img src="../.gitbook/assets/image (171).png" alt=""><figcaption></figcaption></figure>

En la barra de búsqueda, escribe cualquier dato del suscriptor:

* Nombre completo
* Número de teléfono
* Dirección IP o número de ID

Al seleccionar un cliente, su tarjeta de perfil muestra:

* Nombre, ID, fecha de vencimiento, IP y teléfono.
* Plan contratado y servicios adicionales.
* Estado de cuenta y saldo pendiente, si existe.



### Elegir una modalidad de cobro

Selecciona la opción que corresponda al pago del suscriptor.

#### Pago sugerido

Esta es la opción predeterminada.

Si existe saldo vencido, el sistema calcula el importe para liquidarlo. Si la cuenta está al corriente, sugiere la tarifa mensual normal. El monto se calcula automáticamente para evitar errores de captura.

<figure><img src="../.gitbook/assets/image (172).png" alt=""><figcaption></figcaption></figure>

#### Pagar varios meses

Selecciona entre 2 y 12 meses con los botones rápidos.

El desglose indica los meses vencidos cubiertos y los meses adelantados. También muestra la tarifa mensual multiplicada por los meses seleccionados.

<figure><img src="../.gitbook/assets/image (173).png" alt=""><figcaption></figcaption></figure>

#### Registrar un abono

Usa esta opción para pagos parciales o anticipos.

Escribe el importe recibido del suscriptor. El sistema muestra el pago aplicado y el saldo pendiente en tiempo real.

<figure><img src="../.gitbook/assets/image (174).png" alt=""><figcaption></figcaption></figure>

### Agregar cargos y método de pago

Selecciona un método de pago antes de procesar el cobro. Por ejemplo: efectivo, transferencia, depósito o abono.

<figure><img src="../.gitbook/assets/image (175).png" alt=""><figcaption></figcaption></figure>

### Procesar el cobro

Haz clic en **Procesar cobro** para confirmar el pago.

El sistema actualiza la cuenta y ajusta la fecha de vencimiento. También reduce o liquida el saldo pendiente.

Si el servicio estaba suspendido por falta de pago, se reactiva automáticamente. El sistema envía la orden de reactivación a la red.

El suscriptor recibe una confirmación por WhatsApp con los datos del comprobante. Si hay una impresora térmica configurada, se imprime el recibo automáticamente.

<figure><img src="../.gitbook/assets/image (177).png" alt=""><figcaption></figcaption></figure>

### Consultar el comprobante con código QR

Al finalizar el cobro, aparece una ventana con un código QR.

Escanéalo con un teléfono o tableta para abrir el ticket PDF en línea. Así puedes enviar o guardar el comprobante sin imprimirlo.

<figure><img src="../.gitbook/assets/image (176).png" alt=""><figcaption></figcaption></figure>

También puedes seleccionar **Ver PDF** para visualizar, descargar o reimprimir el comprobante.
