# Servicios Extra

<figure><img src="../.gitbook/assets/image (158).png" alt="Vista de servicios extra"><figcaption><p>Vista de servicios extra</p></figcaption></figure>

Los servicios extra son productos, complementos o cargos recurrentes adicionales al plan de Internet.

Puedes usarlos para conceptos como renta de router Mesh, IP pública adicional, televisión IPTV o mantenimiento de cableado. El sistema agrega el cargo a la facturación mensual de cada cliente suscrito.

### Indicadores de la vista

En la parte superior verás indicadores del catálogo:

* **Servicios activos:** cantidad de servicios registrados.
* **Precio promedio:** costo mensual promedio de los servicios disponibles.
* **Clientes suscritos:** total de clientes con al menos un servicio extra activo.

### Crear un servicio extra

1. Selecciona **Nuevo servicio extra**.
2. Ingresa el **nombre del servicio**.
3. Define el **precio mensual**.
4. Añade una **descripción** con los detalles incluidos.
5. Guarda el servicio.

El precio definido se cobrará mensualmente a los clientes que contraten el servicio.

### Consultar el catálogo

<figure><img src="../.gitbook/assets/image (159).png" alt="Catálogo de servicios extra"><figcaption><p>Catálogo de servicios extra</p></figcaption></figure>

La tabla muestra todos los servicios adicionales registrados. Cada fila incluye:

* **Nombre** e identificador del servicio.
* **Descripción** y **precio mensual**.
* **Clientes suscritos** con el servicio activo.

### Editar un servicio

Selecciona el botón amarillo con el ícono de lápiz. Puedes actualizar el nombre, precio mensual o descripción.

### Eliminar un servicio

Selecciona el botón rojo con el ícono de papelera para eliminar un servicio del catálogo.

{% hint style="info" %}
Eliminar un servicio no borra el historial de cobros de los clientes suscritos. El servicio dejará de estar disponible para nuevas contrataciones.
{% endhint %}
